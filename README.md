# Bangladesh News and Culture 🌎📰

Comprehensive resource for Bangladesh news and cultural information.

Get the latest updates on **politics, economy, technology, sports, and entertainment** with **24/7 real-time updates** and a clean, fast UI.

---

## 🔴 Live Demo
**👉 [https://bbn-news.vercel.app](https://bbn-news.vercel.app)**

---

## ✨ Features

- ⚡ **Real-time news updates** from various Bangladeshi sources
- 🗂️ **Category-wise news:** Politics, Economy, Tech, Sports, Entertainment
- 📱 **Fully responsive** - Mobile, Tablet, Desktop
- 🌙 **Clean & fast UI** with smooth interactions
- 🔍 **Search & filter** functionality
- 🇧🇩 **Focused on Bangladesh** culture & current affairs

---

## 🛠️ Tech Stack

- **Frontend:** React, Next.js
- **Styling:** Tailwind CSS
- **Deployment:** Vercel
- **Language:** JavaScript (ES6+)

---

## 🚀 How to Run Locally

```bash
# 1. Clone the repository
git clone https://github.com/bbfakash/bangladesh-news-and-culture.git

# 2. Navigate to the folder
cd bangladesh-news-and-culture

# 3. Install dependencies
npm install

# 4. Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the application.
