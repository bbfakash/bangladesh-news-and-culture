Bangladesh Best News (BBN) 🌎📰
All updates of Bangladesh in one place, first and fast.

Get the latest news on politics, economy, education, technology, sports, and entertainment. 24/7 updates with a clean, fast UI.

BBN Banner

🔴 Live Demo
👉 https://bbn-news.vercel.app (তোমার লাইভ লিংক এখানে বসাবে)

✨ Features
⚡ Real-time news updates from various Bangladeshi sources
🗂️ Category wise: Politics, Economy, Tech, Sports, Entertainment
📱 Fully Responsive - Mobile, Tablet, Desktop
🌙 Clean & Fast UI
🔍 Search & Filter
🇧🇩 Focused on Bangladeshi culture & current affairs
🛠️ Tech Stack
Frontend: HTML5, CSS3, JavaScript (React / Next.js - তুমি যেটা ব্যবহার করো সেটা রাখবে)
Styling: Tailwind CSS / Vanilla CSS
Deployment: Vercel / Netlify
API: Custom News API / RSS

🚀 How to Run Locally
bash
# 1. Clone the repo
git clone https://github.com/bbfakash/BBN-.git

# 2. Go to folder
cd BBN-

# 3. If using npm
npm install
npm run dev

# If only HTML/CSS/JS, just open index.html
